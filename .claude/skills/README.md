# Project Skills

This project keeps only the skills that directly support the Unified Service
Scheduler backend assessment.

| Skill | Purpose |
|---|---|
| `mk-plan` | Architecture and implementation planning |
| `implement` | Execute an approved plan or specification |
| `test` | Unit, integration, end-to-end, and concurrency verification |
| `code-review` | Review changes against project standards and the specification |
| `mk-security` | STRIDE/OWASP-oriented security review |
| `docs` | Maintain project and architecture documentation |
| `git` | Safe commits, pushes, pull requests, and branch merges |

Frontend design, branding, issue-tracker automation, release pipelines, and
toolkit-maintenance skills were intentionally removed because they are outside
the selected backend scope.
